Every Keyboard Size Explained: Full-Size, TKL, 75%, 65%, 60% and 40%

Full-size, 1800, TKL, 75%, 65%, 60%, 40%, ortholinear, split and the standalone numpad: what each keyboard size keeps, what it drops, and who it's for.

Picking a keyboard size matters more than picking a brand, and it costs nothing to get right. Here’s every size from biggest to smallest, plus two odd shapes and the cheat code most people miss. Key counts are approximate.

1. Full-size (~104 keys)

The classic: letters, numbers, the function row, arrow keys, and a full number pad on the right. If you live in spreadsheets, that numpad is pure speed. The catch is that it’s about 18 inches wide, so your mouse hand ends up somewhere near the next zip code.

2. 1800 / compact full-size

Take a full-size and delete the gaps. You keep the numpad, arrows and function row, just squeezed together, which saves a few inches of desk. Great for number crunchers who are tired of reaching. Give your muscle memory a week, because a few keys move.

3. TKL, or tenkeyless (~87 keys)

It removes the number pad and nothing else, so every other key is exactly where you expect it. Your mouse slides a few inches closer, which is why gamers love it. It’s the easiest upgrade on this list: you lose almost nothing unless you’re an accountant.

4. 75% (~84 keys)

Basically a TKL on a diet. The function row stays, the arrows stay, and the navigation keys stack into one column on the right. If you still hit F5 and F12 all day, this is the sweet spot.

5. 65% (~68 keys)

Now the function row is gone, but you keep the arrow keys. Need F5? Hold Fn and the number row becomes F1 to F12. Small enough to throw in a backpack, normal enough that you won’t hate typing on it.

6. 60% (~61 keys)

This is where it gets controversial. The arrow keys disappear too, leaving just the main typing area. Arrows, Delete, Home and End all hide behind a layer. Your mouse gets tons of room, but if you edit text all day you’ll press Fn more than your own name.

Small-keyboard tip: on 60% and 65% boards, Home and End usually live on Fn + arrow keys. Our Home / End guide has the Mac version too.

7. 40% (40–50 keys)

No number row. At all. Typing a single number means switching layers. Fans say their fingers never leave the home row; everyone else calls it a calculator with commitment issues. A fun weekend project with the steepest learning curve here.

The odd shapes

Ortholinear. Every key sits in a perfect grid with straight columns, so your fingers move straight up and down. Some people swear it’s more efficient. Everyone else spends the first week hitting the wrong key.

Split. Two halves you place at shoulder width, so your wrists stay straight, and many tilt up in the middle too. If typing hurts, start here. It looks weird; your wrists won’t care.

The cheat code: a standalone numpad

Seventeen keys, and the trick most people miss. Get a TKL or 65%, and plug in a separate numpad only when you need numbers. Put it on the left so your mouse stays close. Tax season? Plug it in. The rest of the year? Drawer.
