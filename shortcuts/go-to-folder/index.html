Go to a folder by typing its path

Lets you type or paste a folder path and jump straight there.

WindowsCtrl+L
Mac⌘+⇧+G

How to use it

  1. Open File Explorer or Finder.
  2. Press the shortcut.
  3. Type or paste a path, for example ~/Downloads or C:\Users, and press Enter.

Pro tip

On a Mac, ⌘ + ⇧ + G is the only easy way into hidden folders like ~/Library.

Heads up: On Windows, this selects File Explorer's address bar (Alt + D does the same).
