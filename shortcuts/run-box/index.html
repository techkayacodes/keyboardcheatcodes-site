Open the Run box

Opens Run, a tiny box that launches programs and folders by name.

WindowsWin+R
MacNo built-in shortcut

How to use it

  1. Press Win + R.
  2. Type a command, for example 'notepad', 'cmd', or '%temp%'.
  3. Press Enter.

Pro tip

Useful ones: 'control' (Control Panel), 'appwiz.cpl' (uninstall programs), 'msconfig' and 'shell:startup'.
