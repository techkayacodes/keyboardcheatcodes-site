Clipboard history

Shows the last things you copied, not just the latest, so you can paste any of them.

WindowsWin+V
MacNo built-in shortcut

How to use it

  1. Press Win + V. The first time, Windows asks to turn it on. Say yes.
  2. Copy a few things as normal.
  3. Press Win + V again and click any item to paste it.

Pro tip

Pin the things you paste all the time (your address, an email signature) with the pin icon and they'll stay through restarts.

Heads up: Mac has no built-in shortcut for this. Clipboard managers like Maccy add one.
