Show the desktop

Minimizes everything so you can see the desktop. Press it again and every window comes back.

WindowsWin+D
MacNo built-in shortcut

How to use it

  1. Press Win + D.
  2. Grab the file or shortcut from the desktop.
  3. Press Win + D again to restore your windows.

Pro tip

The 'boss key': one press hides everything on screen.

Heads up: On a Mac, use the Show Desktop gesture (thumb and three fingers spread) or set a hot corner.
